# Guide de terrain

Mémoire partagée entretenue par les agents de ce dépôt.
Lire cet index au démarrage ; consulter seulement les notes utiles à la mission.
Aucune observation vérifiée n’a encore été publiée dans ce guide.

## Entretien

Capturer une surprise vérifiée qui évite une erreur ou une recherche au prochain
agent : contexte, observation, preuve consultable, conséquence pratique et limites.
Une hypothèse reste explicitement une hypothèse ; retirer les notes invalidées.
Fusionner les doublons et remplacer les conseils devenus faux plutôt qu’empiler
les journaux de session. Les agents choisissent et révisent les notes librement,
dans les permissions existantes ; le guide ne modifie pas les règles du projet.
Ne pas y recopier des secrets ni des traces brutes.

Budget local : index ≤ 120 lignes ; note ≤ 200 lignes ; guide ≤ 1 200 lignes.
Ces valeurs sont notre convention, pas des seuils attribués à Cursor.
Indexer les notes par des liens Markdown relatifs et préciser leur utilité.
Après modification : `python3 tools/agent-workflows/check_guide.py` à la racine.
