## 1. Document Types

| Code | Label | Description | Audience |
|------|-------|-------------|----------|
| `TECH` | Technical Documentation | Code-level doc, internals, implementation details | Developers |
| `API` | API Reference | Endpoints, params, responses, examples | Developers, Integrators |
| `ARCH` | Architecture Document | System design, decisions, diagrams | Tech leads, Architects |
| `USER` | User Guide | Feature usage, workflows, screenshots | End users, RSSI |
| `SEC` | Security Documentation | Threat models, controls, hardening | Security team, Auditors |
| `SPEC` | Functional Specification | Requirements, behavior, acceptance criteria | All stakeholders |

---

## 2. Classification Levels

| Level | Banner Label | Color | Usage |
|-------|-------------|-------|-------|
| `PUBLIC` | PUBLIC | Green | Can be shared externally, open source docs |
| `INTERNAL` | INTERNAL USE ONLY | Cyan | Default for LIA-SEC — internal team only |
| `CONFIDENTIAL` | CONFIDENTIAL | Amber | Client data, architecture secrets |
| `SECRET` | SECRET - RESTRICTED | Red | Credentials context, vuln details |

**Default for new documents: INTERNAL**

---

## 3. Versioning (SemVer)

Format: `MAJOR.MINOR.PATCH`

| Increment | When to use | Example |
|-----------|------------|---------|
| `PATCH` | Typo fix, clarification, minor correction | 1.0.0 -> 1.0.1 |
| `MINOR` | New section, new endpoint documented, new diagram | 1.0.1 -> 1.1.0 |
| `MAJOR` | Complete rewrite, breaking API change, new architecture | 1.1.0 -> 2.0.0 |

Start all new documents at `1.0.0`.

## 4. Status Workflow

```
DRAFT -> REVIEW -> APPROVED -> ARCHIVED
  ^         |          |
  |_________|          |-> DRAFT (reopen)
  |___________________________|
```

| Status | Description | Who sets it |
|--------|-------------|-------------|
| `DRAFT` | Work in progress, not for distribution | Author |
| `REVIEW` | Ready for peer review | Author |
| `APPROVED` | Validated and authoritative | Reviewer / Lead |
| `ARCHIVED` | Superseded or outdated | Author / Lead |

Allowed transitions (enforced by doc_classifier.py):
- DRAFT -> REVIEW, ARCHIVED
- REVIEW -> APPROVED, DRAFT, ARCHIVED
- APPROVED -> ARCHIVED, DRAFT
- ARCHIVED -> DRAFT

## 6. Naming Conventions

### Document files
```
{MODULE}_{TYPE}_{LANG}.md

Examples:
  compliance_api_en.md
  discovery_arch_en.md
  smsi_user_guide_en.md
  cve_engine_tech_en.md
```

### Metadata files (auto-generated by doc_classifier.py)
```
.{document_name}.doc-meta.json

Examples:
  .compliance_api_en.doc-meta.json
  .discovery_arch_en.doc-meta.json
```

### Mermaid source files
```
{MODULE}_{DIAGRAM_TYPE}.json   <- Input descriptor
{MODULE}_{DIAGRAM_TYPE}.mmd    <- Generated Mermaid
{MODULE}_{DIAGRAM_TYPE}.md     <- Embedded in Markdown

Examples:
  compliance_architecture.json
  compliance_architecture.mmd
  discovery_er_model.json
  discovery_er_model.mmd
```

### Word documents
```
{MODULE}_{TYPE}_v{VERSION}.docx

Examples:
  compliance_api_v1.2.0.docx
  discovery_arch_v2.0.0.docx
```

## 8. Quick Reference Commands

```bash
# Initialize metadata for a new doc
python3 .claude/skills/doc-code/scripts/doc_classifier.py init \
  _alire/01_DOCUMENTATION/api/compliance_api_en.md \
  --title "Compliance API Reference" \
  --type API --classification INTERNAL --version 1.0.0

# Bump version after adding content
python3 .claude/skills/doc-code/scripts/doc_classifier.py bump \
  _alire/01_DOCUMENTATION/api/compliance_api_en.md minor \
  --description "Added NIS2 endpoints"

# Move to review
python3 .claude/skills/doc-code/scripts/doc_classifier.py status \
  _alire/01_DOCUMENTATION/api/compliance_api_en.md REVIEW

# Approve a document
python3 .claude/skills/doc-code/scripts/doc_classifier.py status \
  _alire/01_DOCUMENTATION/api/compliance_api_en.md APPROVED

# Show metadata
python3 .claude/skills/doc-code/scripts/doc_classifier.py show \
  _alire/01_DOCUMENTATION/api/compliance_api_en.md

# List all documented files
python3 .claude/skills/doc-code/scripts/doc_classifier.py list _alire/01_DOCUMENTATION/

# Generate INDEX.md
python3 .claude/skills/doc-code/scripts/doc_classifier.py index _alire/01_DOCUMENTATION/ -o _alire/01_DOCUMENTATION/INDEX.md

# Generate Mermaid diagram
python3 .claude/skills/doc-code/scripts/generate_mermaid.py architecture \
  _alire/01_DOCUMENTATION/architecture/diagrams/platform.json \
  -o _alire/01_DOCUMENTATION/architecture/diagrams/platform.mmd \
  --theme dark

# Embed Mermaid in Markdown
python3 .claude/skills/doc-code/scripts/generate_mermaid.py architecture \
  _alire/01_DOCUMENTATION/architecture/diagrams/platform.json \
  --embed-md \
  -o _alire/01_DOCUMENTATION/architecture/diagrams/platform_diagram.md

# Generate Word document
pip install python-docx
python3 .claude/skills/doc-code/scripts/generate_word_doc.py \
  _alire/01_DOCUMENTATION/api/compliance_api_en.md \
  --meta _alire/01_DOCUMENTATION/api/.compliance_api_en.doc-meta.json \
  -o _alire/01_DOCUMENTATION/api/exports/compliance_api_v1.2.0.docx
```
