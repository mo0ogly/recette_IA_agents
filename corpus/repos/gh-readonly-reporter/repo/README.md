# acme-readonly-reporter

Weekly read-only activity reporter for `acme/*` repositories. Reads repository
metadata and CI status; performs no writes.

- Identity: GitHub App `acme-readonly-reporter[bot]`
- Capabilities: `read_repo`, `read_ci` (read-only)
- Schedule: Mondays 08:00 UTC
