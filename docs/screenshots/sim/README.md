# /sim red-team -- live UI reference

These screenshots are the live visual reference for the red-team recette view
(`/sim` in the console). They are **regenerated by the versioned smoke**, not
captured by hand, so they never go stale: every `./recette.sh smoke` run
re-renders the real console (Chromium -> console 5173 -> API 8090) and
overwrites the PNGs here via `scripts/smoke_console.py::_verify_sim_redteam`.

| File | Tab | What it shows |
|------|-----|---------------|
| `sim_scorecard.png` | Scorecard | CLI mirror of `recette redteam`: total / anomalies attrapees / conformes sans fausse alarme / ratees + OWASP ASI breakdown |
| `sim_maf.png` | Sujets MAF | 6 MAF scenario cards, each with a `sim-caught` "attrapee" badge fed live from `GET /sim/scenarios` |
| `sim_git.png` | Agents Git (Lane B) | 5 git scenario cards (all 4 violation_types + 1 resisted) fed live from `GET /sim/git-scenarios` |

## Regenerate

```
./recette.sh platform up
./recette.sh console start
./recette.sh smoke
```

The smoke asserts the wiring (badge count >= 1 per tab, `rt-diagnostic-overreach`
shows the `sim-caught` "attrapee" badge) AND writes the PNGs above. A stale class
or text name fails the smoke -- the screenshots and the assertions move together.
